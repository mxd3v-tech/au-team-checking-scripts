# PNETLab Checker

Инструмент для автоматической проверки лабораторных работ студентов на платформе PNETLab / EVE-NG.
Поддерживает два интерфейса: веб-браузер и консоль (curses TUI).

## Требования

**Python**: 3.9+

**Системные зависимости** (должны быть установлены в ОС):
```
apt install sshpass
```

**Python-зависимости**:
```
pip install -r requirements.txt
```

> `pexpect` — опционально (нужен только для проверки роутеров EcoRouterOS).
> Если не установлен, проверки роутеров пропускаются.

## Запуск

**Веб-интерфейс** (Flask на 0.0.0.0:5000):
```
python3 main.py
```

**Консольный интерфейс** (curses TUI):
```
python3 main.py --cli
```

Вход в веб-интерфейс: `admin` / `password`

## Конфигурация

Узлы PNETLab хранятся в `nodes.json`. При первом запуске создаётся файл с узлом
`192.168.102.39` (можно изменить через веб-интерфейс или отредактировать файл напрямую).

```json
[
  {
    "name": "pnet-main",
    "ip": "192.168.102.39",
    "username": "api",
    "password": "..."
  }
]
```

## Структура каталогов

```
.
├── main.py                        # Основной файл (web + CLI)
├── app.py                         # Шим для обратной совместимости
├── requirements.txt
├── nodes.json                     # Настройки узлов PNETLab
├── assignment_checker_*.py        # Чекеры (статические)
├── assignment_template.py         # Шаблон для генерации вариантов
├── generated_variants/            # Сгенерированные варианты заданий
├── logs/                          # Логи проверок и сводные таблицы
│   ├── outstend_<чекер>_<студент>-<ip>.txt
│   └── summary_<чекер>-<ip>.txt
├── templates/
│   └── index.html
└── static/
    └── style.css
```

## Логи

Все логи проверок сохраняются в каталог `logs/`:
- **Индивидуальный лог**: `logs/outstend_{чекер}_{студент}-{ip-узла}.txt`
- **Сводная таблица**: `logs/summary_{чекер}-{ip-узла}.txt` (TSV: студент / вариант / балл)

## Добавление чекера

Создайте файл `assignment_checker_<название>.py` в корне проекта с функцией:

```python

    # vm_ports: {"ИМЯ-ВМ": "порт SSH", ...}  — порт "N/A" если ВМ не запущена
    ...
    return score, log_lines
```

Чекер появится в выпадающем списке автоматически.
